Miami Central also loads an Open Sans stylesheet, but it was not the computed font on the inspected directory page. Use the computed stack; no external font download required.

Observed reference: white header and content surfaces, red campus wordmark, neutral borders, restrained navigation and sans-serif text. Proposed FundPath choices: university red `#c3142d`, white surfaces, warm near-white canvas `#fafafa`, text `#22252b`, muted text `#626670`, borders `#e8e8eb`, 12px corners, 24px section gaps. These spacing/color choices are implementation decisions rather than extracted Miami Central measurements.

Jeff branch reference: `RedHawk Finance (3).html` at commit `34fbf9cda942a803641a58744cc86f80be4fea4a`. Adopt the compact role switch, seven-step organization progress and queue-first review pattern. Preserve FundPath's white/red direction and existing funding logic; do not import Jeff's separate application state, database integration or dark theme.

The current iteration follows the user-supplied `RedHawk Finance (3) (1).html` layout: compact header role pills, numbered journey rail and a bordered work panel. White surfaces and red `#b0142b` actions replace the reference's dark theme. The body uses an 18px Source Sans 3 / Segoe UI / Arial sans-serif stack; the system fallback works without a font download. Headings are 30–36px, controls 18px, and primary touch targets at least 48px. The seven-step rail collapses behind a button on phones.

Each role starts with one next action. There is no default dashboard of financial KPI cards. The organization reviews one proposal section and one event or expense at a time, then explicitly submits. A reviewer opens a queue first and one selected request second. Purchase and receipt forms have dedicated screens. Detailed eligibility, rules, payloads and history remain in More tools or disclosures. Labels use sentence case. Expansions of abbreviations apply to display text only; identifiers, exported forms and accounting codes retain their stored values.

Public organization data must show its source and checked time and never overwrite sample financial balances, training status or approvals. The public ElevenLabs agent ID remains saved. Live voice and other paid services are paused until billing is verified and separately authorized; the interface never claims a trial or a live connection has been verified.
